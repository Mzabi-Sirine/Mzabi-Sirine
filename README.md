## Projets

### MCP Threat Intelligence

Serveur MCP de renseignement sur les menaces conçu comme un plan de contrôle : chaque requête est
authentifiée, autorisée, filtrée et tracée avant d'atteindre les données.

- Six outils en lecture seule, protocole MCP `2025-06-18`, Python standard library uniquement.
- Jetons de capacité HMAC-SHA256, politique ABAC, masquage par classification, neutralisation
  des injections, journal d'audit chaîné.
- 31 scénarios de tests, 16/16 attaques bloquées, 3/3 injections neutralisées.
- Rapport, présentation, captures et démonstrations disponibles dans le dépôt.

**[Voir le projet](https://github.com/Mzabi-Sirine/mcp-threat-intelligence)**

### AvocatPro

Application web de prise de rendez-vous pour un cabinet d'avocat, avec un module dédié à la
préfecture (ANEF).

- PHP 8 sans framework, SQLite via PDO et MySQL via MySQLi.
- Inscription et connexion avec hachage des mots de passe, espace personnel, historique des demandes.
- Requêtes préparées et échappement des sorties.

**[Voir le projet](https://github.com/Mzabi-Sirine/AvocatPro)**
